# ResearchForge AI

**ResearchForge AI** is an offline academic publication assistant powered by Gemma 4 that converts raw research information into IEEE-compliant publication assets while preserving data privacy.

## Features

* IEEE paper generation from raw project inputs
* Overleaf-compatible LaTeX code generation
* Architecture and workflow diagram generation (Mermaid)
* Automatic figure and table planning
* IEEE reference formatting support
* Fully offline processing using a local LLM
* Research confidentiality and intellectual property protection

## Problem Statement

Researchers often rely on cloud-based AI tools for academic writing, requiring sensitive research data to be uploaded to external servers. This raises concerns regarding privacy, intellectual property, and confidentiality.

ResearchForge AI addresses this challenge by providing a local, offline solution for generating publication-ready IEEE research documents.

## Workflow

1. Input research details (title, objectives, methodology, results, etc.)
2. Analyze publication requirements
3. Generate IEEE paper sections
4. Create diagrams, tables, and figure captions
5. Produce Overleaf-ready LaTeX code
6. Export publication assets

## Technology Stack

* **LLM:** Gemma 4 E2B
* **Inference:** LM Studio
* **Frontend:** Gradio
* **Backend:** Python
* **Documentation:** LaTeX / Overleaf
* **Diagram Generation:** Mermaid

## Output Deliverables

* IEEE Paper Draft
* LaTeX Source Code
* Architecture Diagram

* Figure Captions
* Table Templates
